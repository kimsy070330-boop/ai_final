# 노노그램 C 단위 테스트 샘플

PDF에 나열된 함수가 아니라 직접 구성한 노노그램 모듈을 위한 단위 테스트입니다.

## 빌드 및 실행

```bash
make test
```

## 테스트 대상 함수

- `nonogram_init`
- `nonogram_is_valid_position`
- `nonogram_set_cell`
- `nonogram_toggle_cell`
- `nonogram_get_row_hint`
- `nonogram_get_col_hint`
- `nonogram_check_row`
- `nonogram_check_col`
- `nonogram_is_solved`
- `nonogram_reset`
